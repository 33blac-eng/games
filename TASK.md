# Завдання: найкраща якість картинки у віддаленому доступі oo-screen

## Що це
Свій віддалений робочий стіл: агент на Windows (Go: захоплення екрана → H.264) → хаб (Go, WebRTC/WebTransport, fan-out, бітрейт) → браузер (JS, `desktop-oo-webrtc.js`).
- Агент: `tools/oo-screen/agent/` (capture, encode, oo-agent)
- Хаб: `tools/oo-screen/hub/cmd/hub-webrtc/` (`bitrate.go`, `fanout.go`)
- H.264 утиліти: `tools/oo-screen/internal/h264`
- Плеєр: `total-erp-app/resources/js/remote/desktop-oo*.js`
- План і історія: `tools/oo-screen/PLAN-waves.md`, `README.md`

## Відомі пастки
- Chrome НЕ приймає H.264 High через WebRTC — лише Constrained Baseline/Main. Профіль `64002a` = старий агент, `4d40xx` = новий. Порушиш — хаб віддасть 415.
- Цільові машини — слабкі офісні ПК, часто без GPU-енкодера; мережа — звичайний офісний інтернет.

## Що зробити (по черзі, кожен крок — окремий звіт)
1. **Аудит якості.** Пройди весь ланцюг захоплення → кольорове перетворення → енкодер → пакетизація → бітрейт-контроль → декодер у браузері. Знайди кожне місце, де губиться якість: chroma subsampling 4:2:0 на тексті, неправильна матриця BT.601/709 і діапазон full/limited, масштабування, GOP/keyframe, QP, rate control, втрати й NACK/PLI, jitter buffer, DPI/HiDPI. Таблиця: місце (файл:рядок) → проблема → вплив → як виправити.
2. **Порівняння зі світовим рівнем** (Parsec, RustDesk, Chrome Remote Desktop, Moonlight/Sunshine, AnyDesk): що вони роблять для різкого тексту й низької затримки (4:4:4, AV1/HEVC screen-content tools, dirty-rects, lossless refine статичних регіонів, adaptive QP for text). Що реально застосовно тут з урахуванням обмеження Chrome.
3. **План покращень** за пріоритетом: виграш якості / ризик / складність.
4. **Реалізація** топ-пунктів у коді з тестами (`go test ./...` має бути зелений; існуючі `*_test.go` не ламати). Окремий коміт на кожне покращення.
5. **Метрики.** Інструмент (у `bench/`), що рахує PSNR/SSIM/VMAF і різкість тексту до/після на корпусі скріншотів робочого столу (таблиці Excel, код, дрібний шрифт). Цифри до і після кожного коміту.
